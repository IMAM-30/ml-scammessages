GitHub Pages dipakai untuk modul, bukan menjalankan model asli.

GitHub Pages hanya menyajikan HTML, CSS, dan JavaScript statis. Checkpoint PyTorch `.pth`, tokenizer Transformers, dan inference IndoBERT tetap membutuhkan Python runtime. Jadi halaman ini aman dibuka dari HP sebagai materi belajar, sementara prediksi nyata dijalankan dari laptop lewat Streamlit.

Peta besar

Alur sistem dari data sampai UI

Proyek ini punya dua jalur: jalur training di Kaggle untuk menghasilkan model, dan jalur lokal di laptop untuk memuat artifact lalu memberi prediksi lewat UI.

1

Dataset

File `indo_spam.csv` dibaca dari Kaggle Input dengan kolom `Kategori` dan `Pesan`.

2

Training

Notebook menjalankan preprocessing, tokenizer, SVM, IndoBERT, dan Hybrid BiLSTM.

3

Artifact

Model `.pth`, tokenizer, split data, hasil evaluasi, dan config disimpan ke output Kaggle.

4

Inference

`app/inference.py` memuat artifact, membersihkan teks, lalu menghitung probabilitas scam.

5

UI & Modul

Streamlit untuk prediksi asli. `docs/index.html` untuk modul GitHub Pages.

Data dan target

Target model adalah klasifikasi biner: `0` untuk normal/ham dan `1` untuk scam/spam. Dataset cukup seimbang, sehingga metrik precision, recall, dan F1 bisa dibaca dengan stabil.

URL_PATTERN = re.compile(r"https?://\S+|www\.\S+", flags=re.IGNORECASE)
MENTION_PATTERN = re.compile(r"@\w+")
HASHTAG_PATTERN = re.compile(r"#(\w+)")

def clean_text(text):
    text = str(text).lower()
    text = URL_PATTERN.sub(" link ", text)
    text = MENTION_PATTERN.sub(" user ", text)
    text = HASHTAG_PATTERN.sub(r"\1", text)
    text = re.sub(r"[^a-z0-9\s]", " ", text)
    words = []
    for word in text.split():
        word = normalize_repeated_chars(word)
        word = SLANG_DICT.get(word, word)
        words.extend(word.split())
    return REPEATED_SPACE_PATTERN.sub(" ", " ".join(words)).strip()

def evaluate_binary(y_true, y_prob=None, y_pred=None, threshold=0.5):
    if y_pred is None:
        y_pred = (np.asarray(y_prob) >= threshold).astype(int)
    metrics = {
        "accuracy": accuracy_score(y_true, y_pred),
        "precision": precision_score(y_true, y_pred, zero_division=0),
        "recall": recall_score(y_true, y_pred, zero_division=0),
        "f1": f1_score(y_true, y_pred, zero_division=0),
        "threshold": threshold,
    }
    return metrics

def predict_scam(text, model=None, threshold=None):
    model.eval()
    cleaned = clean_text(text)
    encoding = tokenizer(
        cleaned,
        truncation=True,
        padding="max_length",
        max_length=CONFIG["max_length"],
        return_tensors="pt",
    )
    with torch.no_grad():
        logits = model(input_ids=input_ids, attention_mask=attention_mask)
        prob = logits_to_positive_probs(logits).item()
    label = "SCAM/SPAM" if prob >= threshold else "NORMAL/HAM"

Server-side model logic

Cara inference lokal bekerja

File `app/inference.py` adalah jembatan antara artifact training dan UI. Ia memuat model PyTorch, mengulang preprocessing yang sama, lalu menghasilkan prediksi.

1

Load dependency

`torch`, `transformers`, dan komponen BERT dimuat. Jika belum ada, engine memberi pesan install requirements.

2

Load artifact

Engine membaca checkpoint Hybrid, tokenizer, threshold 0.68, dan preprocessing config.

3

Rebuild arsitektur

Arsitektur Hybrid dibangun ulang lokal, lalu `state_dict` dari checkpoint dimasukkan.

4

Clean dan tokenize input

Teks pengguna dibersihkan, dipotong/padding 128 token, lalu dikirim ke model.

5

Output prediksi

Model mengeluarkan probabilitas scam. Jika `prob_scam >= threshold`, hasilnya `SCAM/SPAM`.

Contoh scam tervalidasi

"Selamat Anda memenangkan hadiah 100 juta..." menghasilkan `SCAM/SPAM`, prob_scam 95.59%, risiko tinggi.

Contoh normal tervalidasi

"Besok kita kumpul jam 10 di kampus..." menghasilkan `NORMAL/HAM`, prob_scam 2.11%, risiko sangat rendah.

def clean_text(self, text: str) -> str:
    value = str(text).lower()
    value = URL_PATTERN.sub(" link ", value)
    value = MENTION_PATTERN.sub(" user ", value)
    value = HASHTAG_PATTERN.sub(r"\1", value)
    value = re.sub(r"[^a-z0-9\s]", " ", value)
    words = []
    for word in value.split():
        word = normalize_repeated_chars(word)
        word = self.slang_dict.get(word, word)
        words.extend(word.split())
    return REPEATED_SPACE_PATTERN.sub(" ", " ".join(words)).strip()

Baris 4Mention akun diganti menjadi `user` agar nama akun tidak menjadi noise.
Baris 5Tanda `#` pada hashtag dibuang, tetapi isi kata tetap dipertahankan.
Baris 6Karakter selain huruf, angka, dan spasi dibuang. Angka tetap dipertahankan karena penting untuk nominal/rekening/kode.

Urutan cerita 30 detik

Proyek ini mendeteksi pesan scam bahasa Indonesia. Data dibersihkan dan dibagi secara stratified, lalu dibandingkan dengan SVM, IndoBERT, dan Hybrid IndoBERT BiLSTM. Training dilakukan di Kaggle, hasilnya disimpan sebagai artifact, kemudian artifact dimuat oleh `app/inference.py` untuk prediksi lokal dan hasilnya ditampilkan oleh Streamlit.

Jawaban saat ditanya "modelnya jalan di mana?"

Model tidak berjalan di GitHub Pages. GitHub Pages hanya modul belajar statis. Prediksi asli berjalan di laptop melalui Python, PyTorch, Transformers, dan Streamlit. File `.pth` dimuat oleh `app/inference.py`, lalu UI hanya mengirim input dan menampilkan hasil.
